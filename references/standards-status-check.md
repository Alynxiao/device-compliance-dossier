# 标准状态核验recipe（GB / YY / ISO）

生成法规标准清单时，**每一个标准号都必须核过状态**。本文是查法，不是背景介绍。

**定位：本文查出的一切（状态、适用条件、核验日期、采标关系）都写进「撰写依据」，不进清单。** 清单里的标准表固定三列：序号 / 标准编号 / 标准名称——**不带状态列、不带适用条件列**。核验工作必须做，但工作痕迹不上对外文件。下文表格里写「交付物」的地方一律指撰写依据。

## 为什么不能偷懒

- 凭记忆写 → 必然掺进已废止标准 → 对方申报被形式审查打回
- 只看平台「现行/废止」→ 漏掉「现行但官方推荐新版」这一档
- 只看第三方文章标题 → 它们把「推荐替代」写成「废止！」搏点击

**唯一可信的两个源：标准平台的状态字段 + 主管部门的过渡说明原文。** 两者冲突时以官方说明为准。

## 源一：全国标准信息公共服务平台（std.samr.gov.cn）

行业标准（YY、YY/T）与国家标准（GB、GB/T）分两个检索区，详情页是**静态渲染**，`web_extract` 可直取。

详情页给出的字段：

```
标准号 / 发布日期 / 实施日期 / 制修订 / 全部代替标准
中国标准分类号 / 国际标准分类号 / 归口单位 / 主管部门
标准状态：发布 YYYY-MM-DD → 实施 YYYY-MM-DD → 废止（空即未废止）
适用范围
相近标准（计划）   ← 高价值：新版/旧版/上位标准常在这里现身
```

**「标准状态」下面列的「发布 / 实施 / 废止」是时间轴三段，不是三个并列状态。** 只有「废止」填了日期才算废止；它为空而正文写「现行」则是现行。误读这一段会得出与事实相反的结论。

**「相近标准（计划）」是免费的交叉校验**：旧版、新版草案、系列标准其他分部、上位标准都会列出来。想确认「有没有新版在路上」先看这里，比搜新闻准。

## 源二：主管部门的过渡说明

标准换代时，归口标委会常发一份说明，搜法：

```
<标准名> 实施相关情况的说明
<新标准号> <旧标准号> 实施 说明
```

这份文件的典型措辞值得记住，因为它决定交付物怎么写：

| 官方原话大意 | 实际含义 | 交付物写法 |
|---|---|---|
| 新版已实施，但旧版因被广泛引用**暂不申请废止** | 两个都现行 | 两个都列，注明等效 |
| 按新版要求开展活动**可视为符合**旧版 | 等效互换 | 推荐引新版，旧版仍可引 |
| 旧版自 YYYY-MM-DD 废止 | 真废止 | 划掉，标替代版 |
| 新版发布，YYYY-MM-DD 实施 | 未实施，期间旧版有效 | 标「将于…实施」 |

## 四档状态归一

| 档 | 判据 | 交付物呈现 |
|---|---|---|
| 现行 | 状态现行、废止字段空、无过渡说明 | 正常列 |
| **现行但推荐新版** | 有过渡说明且旧版未废止 | 两个都列 + 等效说明 |
| 已废止 | 废止字段有日期 | 划掉 + 替代标准号 |
| 未实施 | 实施日期在未来 | 标实施日期，写「期间按 XXXX 版执行」 |

## 标准号归一

写进交付物前把标准号补成完整形式：`GB/T 16886.1-2022`、`YY/T 0663.3-2016`。

- 原文/指导原则只写系列号（`GB/T 16886`）→ 补到实际引用的分部 + 现行年号，并注明「原文未注版本」
- 系列标准要区分分部：血管内器械分 `.1 血管内假体` / `.2 血管支架` / `.3 腔静脉滤器`，**不同分部对应不同产品，不能混用**
- 采标关系要标：`YY/T 0663.3-2016` 采标 `ISO 25539-3`，`GB/T 42062-2022` 采标 `ISO 14971:2019`，`GB/T 16886` 系列采标 `ISO 10993`——出口清单靠这条映射

## 产品属性 → 标准触发关系（这张表进撰写依据，当「适用条件」用）

只补真正触发的那几条，不是把表全堆上去。**清单里不写适用条件，但报告里必须逐条写明**，否则读报告的人不知道 YY/T 1823 为什么要列。

| 属性 | 触发标准 |
|---|---|
| 任何接触人体/植入 | GB/T 16886 系列（生物学评价，按接触等级选分部）；GB/T 42062-2022 风险管理 |
| 无源植入 | YY/T 0640 无源外科植入物 通用要求 |
| 金属植入 | YY/T 0695 腐蚀敏感性；GB/T 24196 电化学试验方法 |
| 镍钛材质 | YY/T 1823 镍离子释放试验方法 |
| 无菌提供 | GB 18279 环氧乙烷 / GB 18280 辐射（注意分部与新版实施日期） |
| 有源电气 | GB 9706.1 医用电气设备 基本安全和基本性能通用要求 |
| 含软件 | YY/T 0664 医疗器械软件 软件生存周期过程 |
| 输送系统为血管内导管 | YY 0285 系列（血管内导管 一次性使用无菌导管） |

**优先找专用标准**：产品名往往有对口标准（如腔静脉滤器对应 `YY/T 0663.3`）。专用标准的价值高于十条通用标准，且常处于修订状态，要单独标注。

## 核验清单（逐条打勾再落笔）

- [ ] 每个标准号都有版本年号
- [ ] 每个标准号都在平台上查过状态
- [ ] 状态为「废止」的已找到替代标准号
- [ ] 状态为「未实施」的已标注实施日期与期间执行版本
- [ ] 有换代关系的已搜过过渡说明，不是只凭平台字段
- [ ] 系列标准选对了分部
- [ ] 专用标准已单独成节，未混进通用里
- [ ] 状态、适用条件、核验日期已写进**撰写依据**，清单里为零命中
