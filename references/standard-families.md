# 通用标准族完整清单（无源植入 + 无菌提供 基线）

**用途**：新接一个产品时，照这份逐个过一遍再增删，避免「凭印象想」漏整族。基线适用于三类医疗器械、无源植入、无菌提供、金属材料、非有源、不含药、不含软件的产品。产品属性不同时要按实际增删，基线只保证「不漏整族」。

**用法**：先按「什么产品必配」列筛掉不适用的族，再按产品属性在本族内增删分部。**不许直接从零列** —— 从零列必漏。

## 完整性判据（数一遍）

符合上述属性的产品，标准数落在 **35~40 条**。少于 30 条基本可以断定漏了族，回去对下面的九个族。

九个族一个都不能少：**体系 / 风险 / 生物学 / 植入物通用 / 材料性能 / 灭菌 / 无菌屏障 / 包装试验+运输 / 标签符号**，外加检验方法。

## 逐族清单

### 1. 体系（任何产品必配）

| 标准 | 现行版本 | 说明 |
|---|---|---|
| GB/T 42061 质量管理体系 用于法规的要求 | **2022** | 等同 ISO 13485:2016。**最常漏的一条**，替代了已废止的 YY/T 0287-2017 |
| GB/T 42062 风险管理对医疗器械的应用 | **2022** | 等同 ISO 14971:2019 |

两者是一对：管体系的 61、管风险的 62。只列 62 不列 61 是逻辑漏洞，会被当面问「为什么没有 42061」。

**YY/T 0316-2016 不要再列**：GB/T 42062-2022 是其事实替代版。官方（SAC/TC221）2025-04-29 明确「因被广泛引用暂不申请废止，按新版做视为符合旧版」——它没死，但清单是「你要符合哪个」，给两个版本等于让人自己判断。等效关系写进撰写依据。

### 6. 包装试验方法 YY/T 0681 系列（无菌提供必配）

**这一族最容易漏，而且漏得最没自觉**——人会记得「要不要做密封强度」，却忘了运输、忘了过程确认、忘了老化。

| YY/T 0681.3 无约束包装抗内压破坏 | 2010 | 耐内压 |
| YY/T 0681.4 染色液穿透法测定透气包装的密封泄漏 | **2021** | **染色渗透查密封** |
| YY/T 0681.5 内压法检测粗大泄漏（气泡法） | 2010 | 粗大泄漏 |
| YY/T 0681.9 约束板内部气压法软包装密封胀破试验 | 2011 | 密封胀破 |

| 标准 | 版本 | 验什么 |
|---|---|---|

| YY/T 0681.12 软性屏障**材料**抗揉搓性 | **2022** | 材料抗揉搓（2014 版已废止；名称从「膜」改为「材料」，搜旧名会查到废版） |

**这个分工判据**：测「**成品包装**」的归企业（密封强度、剥离、染色渗透、运输、老化、目力检测都是拆开卖出去的那个包装袋）；测「**材料本身**」的归供应商（揉搓、戳穿、微生物屏障分等是卷材属性）。把密封强度算成供应商责任是错的，会被直接退回。

**分工结果只进撰写依据，清单不加列**：清单的标准表固定三列（序号 / 标准编号 / 标准名称），**不许加「评估对象」「责任方」这类列**。分工结论写成依据里的一张表：原材料级标「供应商提供数据」——采购成品袋的人不做材料测试，只索取报告；成品级标「企业自行验证」。

### 10. 产品专用（每产品一条）

用产品名去标准库搜「心血管植入物」「血管内器械」这类上位词，往往存在专门分册。腔静脉滤器对应 `YY/T 0663.3-2016 心血管植入物 血管内器械 第3部分：腔静脉滤器`（采标 ISO 25539-3）。

**这是整份清单里最值钱的一条**——漏了等于清单没做。专用标准优先于任何通用标准。

## 第二基线：血管内导管族（非植入 · 接触血液 · 无菌提供）

上面九族是无源**植入**产品的骨架。换成**非植入的血管内导管**（中心静脉导管、PICC、导管鞘、血透用导管套件）时，骨架不变但三处必须调整——照植入基线照拄会列错。

## 查证方法

每条标准的状态都去**全国标准信息公共服务平台**（`std.samr.gov.cn`）核。页面上「1. 发布 / 2. 实施 / 3. 废止」**是时间轴的三格，不是三个状态标签**——只填了前两格就是仍现行，第三格有日期才是真废止（拿那个日期去对替代版）。搜索摘要里出现「废止」二字，多半只是这三格的标题被截断，不能据此判死。

**「即将实施」不等于「现行」**：新版发布到正式实施常隔一两年（GB 18280.1-2025 要到 2029-01-01、GB/T 14233.2-2025 发布后仍未生效）。这种时候清单里必须写旧版——写新版等于让申���按一份还没生效的文件做。

三个不可信的来源：

1. **公众号 / CRO 网站标题写「已废止！」** ——为了点击率把「推荐替代」写成「废止」，必须回到主管部门原话。
2. **平台显示「现行」就以为没事** ——有「现行但推荐新版」的过渡态（YY/T 0316 就是），要去搜「XX标准 实施相关情况的说明」。
3. **自己的记忆** ——标准换版频繁（GB/T 19633 两part 2024 年一起换、GB/T 19973.2 到 2025、YY/T 0466.1 到 2023），凭记忆写的必然掺旧版。
